chat — empty, failed turn, limits

kebi-app · components/chat-screen.tsx · ADR-055 / ADR-136 · applies the kernel

Chat's loading state is the best-designed thing in the app and isn't in question here: the interleaved process, the work chips, the fold into ▸ thought for 12s. What's missing is at the two ends. A first open with no transcript is a blank canvas — the mascot button opens onto nothing but a composer. And a turn that fails prints <Text className="text-danger"> — one red sentence with nothing to tap, on the one screen where the failed thing (your question) is still sitting right above it.

The transcript survives close→reopen, so this is a first open or a cleared history. Note that home already has quick-prompt chips — anything offered here has to not duplicate them, and has to survive the fact that most opens arrive with a seed already sent.

2 · a turn that failed your question is still on screen — use it

Unique to chat: the failed input is right there, one line above. Every other screen has to describe what failed; this one can just point at it. Two flavours — a generic reach failure, and a 429 rate limit, which is not a failure at all but a plan boundary and already has an upgrade toast wired (useUpgradeToast).

A 429 is not an error — nothing broke, you hit a plan boundary — so it takes the --warn dot, not --danger, and offers no retry (retrying is guaranteed to fail). It says when it resets and what the next tier gives, with an explicit "not now" so the upsell has a door out. This is the one error-shaped thing in the app allowed to mention a plan.

chat, decided

1b — kebi speaks first: one short question plus three capability prompts, bottom-aligned so the first real turn pushes them up. Not the home chips repeated; examples of what chat can do that a chip can't.

2b + 2c — a failed turn gets the app's standard error row inside its own slot, keeps its thought for 3s fold, and offers "ask again" that resends the question already on screen. A 429 is warn-toned, retry-less, says when it resets, and is the only error-shaped surface allowed to name a plan.

3a–3c — a stopped turn keeps its partial answer and gains "ask again"; offline is warn-toned but retryable; the streaming process is untouched. And one rule for the whole screen: --danger stops being a body-text colour. It's a 6px dot, and the sentence is ordinary text — same as everywhere else in the app.
