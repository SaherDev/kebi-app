help — sending, sent, failed

kebi-app · app/help.tsx + feedback-form-sheet.tsx · applies the kernel

Help itself has no loading and no empty state: it is four static rows over local data (latestExchange, recentSaveAttempts). Everything happens in the report sheets, and their handling is already thoughtful — a throw keeps the sheet open with the draft intact behind an error toast, precisely so a blip isn't a dead end.

Two things are missing. The send button has no in-flight state (it dims via canSend, but says nothing), and the failure is a toast that fades in three seconds while the user is still looking at the sheet that failed — the one place the app tells you something important somewhere you aren't looking.

1 · sending a report where does the outcome appear?

The sheet is the surface the user is looking at. Anything about this send belongs in it; the toast is for after it closes.

"a wrong answer" attaches the latest chat exchange; "a save that didn't work" attaches recent save attempts. Both read local state, so neither can load or fail — but both can be empty, and today the row looks identical either way.
