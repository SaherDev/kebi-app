3 · zero rule for b · 2 frames

never show a filter that returns nothing

the one point where design and engineering agree exactly. with counts, a chip that would empty the library simply isn't rendered — so the only reachable empty state is a search miss, which is the user's own words and therefore explicable.

this is a rule for b, not work for today. a has no chips to suppress. it's recorded here so that whenever the chip rail does land, it lands with counts — a chip rail without them is the left-hand frame, and shipping that would be a regression against a.

what ships, and what waits

shipping now — a. delete library-sort-sheet.tsx, delete library-filter-sheet.tsx, drop the toolbar row from library-toolbar.tsx. add the paging-loop search and the "3 of 84" line. no backend needed. it is a net deletion — two components out, one wrong answer closed, nothing added but a count that's true.

the one part with teeth: use-library.ts race-guards reads with a monotonic reqId that drops superseded pages. a loop that pages to next_cursor === null has to cooperate with that guard or it cancels itself partway and search silently sees a partial library — the exact bug being fixed, wearing a new hat.

next — §4 area sections. grouping, headers, and counts are all client-side once a's paging loop holds the library, so the bulk of it is a FlatList → SectionList change. the tap destination needs no design and no build: it ships today. the only blocker is that library rows carry city as a display string with no area uri — one field, versus the four b would have needed.

the caveat that doesn't go away: sections are only honest over the whole library. built over paged data, a half-populated "canggu" reads as complete — so §4 depends on a's loop being right, which is the same reqId hazard above, now load-bearing for two features instead of one.

dropped — b. of its three chips only visited and approved have server params today, and those are the two you already don't use. liked, nearby, and per-chip counts would all be new backend work to reach a weaker version of what §4 gives away for free.
