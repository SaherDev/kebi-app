Search is a separate request over the whole stash (useLibrarySearch), flat rather than grouped by area. Today the first keystroke replaces the entire list with a centred spinner, so the screen goes blank while you're still typing. The empty and error cases below are already built — they only need to inherit the kernel's language.

library, decided

1b — hero bar + one area header + three cards, all shimmering. The hero is the count, and a blank 34px hero hole looks more broken than a shimmering one.

2b + 2c + 2d — first search shows two skeleton cards under a shimmering count; refining a query dims the existing results instead of blanking them; "no matches" stays exactly as built; a failed search freezes its skeleton and keeps the query in the field.

3b — retire the mascot empty here. The hero answers itself with nothing saved yet, two ghost cards show what lands, and the add-row is the last card. Keep the pulsing bookmark ring — it costs nothing and teaches the control that persists after the ghost is gone. The mascot keeps its two real jobs: splash and blocking load.

4b + 4c + 4d — frozen skeleton for a failed first load, a centred one-liner where the tail skeleton would be, and a toast for a failed refresh. The tail case is new behaviour: today loadMore failing is silent, and a list that stops paging with no explanation is indistinguishable from a list that ended.
