two notes on this

"retry" or "try again"? The toast mockup says retry; the app's i18n currently says try again. Drawn as retry here to match the design system, but they should agree — worth picking one.

Tapping a place needs its id. Today only names are kept when a share resolves, so the row has nothing to open. Storing the place id alongside the name is what makes the chevron real — the same id the stash row pushes to /place.
