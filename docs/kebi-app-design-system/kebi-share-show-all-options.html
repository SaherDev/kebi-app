what I would do

1 · b. Unfinished pinned, saved rows fill the rest. A failed row that scrolls off is the only row on this card that can actually be lost — every landed place is also in the stash. (c if you want the totals visible; it is b plus one line.)

2 · b. Fold to a single "6 saved · 1 didn't" row that opens the screen. It gives you the fold you asked for without inventing a second control — folded, the card is one row tall and still does something.

3 · b. Grouped by share. It is the only version that answers "what did that video give me", and it is the shape the data already has — one queue entry, N places.

One thing I need from you either way: today ✕ deletes these records, so the screen can only ever show what has not been dismissed. If show all should be a history that survives dismissal, the records need to stop being deleted and start aging out — a small change here in the app, share-storage.ts, no backend work.
