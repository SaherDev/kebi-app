while you were away

kebi-app · apps/mobile home · locked — silent share, queue drained on open

the surface a user meets when they open Kebi after sharing links into it from TikTok or Instagram. the share itself is silent — no Kebi UI, no app launch — so this is the only place the app ever accounts for what it caught.

the eyebrow is the constant. it is present at every count, and it carries the dismiss. the group container appears only at two or more results, per §Group container — "don't use a card for a single item". so this is not two components, it is one eyebrow whose rows gain a container when there are enough of them.

spec

eyebrow
11px / 600 / 0.08em / uppercase / --text-soft. always present. carries the ✕.
container
--surface, 14px radius, 1px --surface-2 between siblings, no border in dark. only at 2+ rows.
single row
no container, no border, sits on --bg. §Group container: a single item is a row, not a card.
dismiss
✕ on the eyebrow, both states. no got it footer — the ✕ already says it, and a footer would only exist in one of the two states.
loading row
skeleton bars in the shape of the incoming row. no spinner. avatar slot shows the source glyph immediately.
failed row
source glyph avatar, url as the name (--text-muted, 500), failure as plain --danger text. no status pill — nothing exists to have a status.
try again
outlined variant, 999px, 13px / 600, compact padding. re-queues that one link.
persistence
survives app close. only the ✕ clears it.
placement
home, above the stash. note the stash card is 18px with an inline header — this one is 14px with an eyebrow, deliberately, until the stash card is brought to spec.
errors
handled in-component. §Error handling stays three tiers — its "recoverable → toast" rule does not apply here, and that exception lives in this component, not the doc.
copy
lowercase throughout. · for inline meta. no exclamation, no title case.
