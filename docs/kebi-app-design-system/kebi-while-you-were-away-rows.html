the honest position

We cannot name a pending share well, and that is a platform limit. TikTok's share sheet passes a link only — no caption in attributedContentText, verified on device. Instagram may differ; the code already prefers a caption when one is offered.

So the naming question is smaller than it looks. A row is only nameless while it is pending. Once kebi answers it is a place, and if kebi answers in seconds — which it does when the link is one it can read — almost nobody ever sees the pending name.

a or b is a taste call, not a correctness one. a is defensive; b is calmer and arguably more honest, since ZSVSgEWX3 is noise a human cannot use.
